# Desktop screenshots (taken by hand)

*Coder: Clone Repository in Workspace…* runs in a **local** VS Code window,
which `capture.mjs` can't drive. Take these in VS Code Desktop with the
light theme (**Light Modern**), the window at about 1280×800, and nothing
private on screen (the account menu closed, no other repositories in view).
Save them under `docs/assets/screenshots/` with these names, then reference
them from `docs/getting-started/first-workspace.md`, step 2.

| File | What to show |
|---|---|
| `desktop-clone-command.png` | The Command Palette with *Coder: Clone Repository in Workspace…* typed and highlighted. |
| `desktop-clone-pick-repository.png` | The repository picker after choosing **GitHub**: the filter box with a few characters typed, and the matching repositories listed. |
| `desktop-clone-pick-branch.png` | The branch list for the picked repository, the default branch first. |
| `desktop-clone-progress.png` | The progress notification, e.g. *Building the image and the workspace…*. |
| `desktop-clone-opened.png` | The new window, connected to the workspace (Coder in the bottom-left remote indicator) and open on the cloned repository. |
| `desktop-clone-existing.png` *(optional)* | *You already have a workspace on …* with **Open …** and **Create Another Workspace**. |
