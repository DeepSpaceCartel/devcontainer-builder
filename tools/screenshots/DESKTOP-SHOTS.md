# Desktop screenshots (optional, taken by hand)

`capture.mjs` now captures the clone command itself in VS Code in the
browser (`clone-*.png`). Two views only exist in VS Code Desktop and are
optional extras:

Take these in VS Code Desktop with the
light theme (**Light Modern**), the window at about 1280×800, and nothing
private on screen (the account menu closed, no other repositories in view).
Save them under `docs/assets/screenshots/` with these names, then reference
them from `docs/getting-started/first-workspace.md`, step 2.

| File | What to show |
|---|---|
| `desktop-clone-github.png` | The repository picker after choosing **GitHub** (needs VS Code's GitHub sign-in): the filter box with a few characters typed, and the matching repositories listed. |
| `desktop-clone-opened.png` | The new Desktop window, connected to the workspace (Coder in the remote indicator, bottom left) and open on the cloned repository. |
